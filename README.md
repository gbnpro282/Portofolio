# Portofolio Guido Bryan Nugroho

Website portofolio statis dengan desain **terang, minimalis, dan bersih** yang dibuat khusus sesuai data kamu.

## Struktur Folder
```text
portofolio-guido/
├── index.html      # Halaman utama portofolio (satu halaman penuh ke bawah)
├── css/
│   └── style.css   # Styling minimalis dengan sistem grid dan layout responsif
├── js/
│   └── script.js   # Filter kategori karya, lightbox gambar, copy email/Discord, dan menu mobile
└── README.md       # Panduan penggunaan
```

## Cara Menjalankan di Komputer
1. Ekstrak file ZIP ini ke folder mana saja.
2. Klik dua kali file `index.html` untuk membukanya langsung di browser (Chrome, Edge, Firefox, atau Safari).

## Cara Publish Gratis ke Internet (GitHub Pages)
1. Buat repository baru di akun GitHub kamu (`gbnpro282`), misalnya bernama `portofolio`.
2. Upload semua isi folder `portofolio-guido` (`index.html`, folder `css`, folder `js`, dan `README.md`) ke repository tersebut.
3. Buka **Settings > Pages** di repository tersebut.
4. Pada bagian **Branch**, pilih `main` dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu 1–2 menit sampai link website kamu aktif.
